# Blackmoon desktop styling

Blackmoon opts into the shared app, shell, launcher and media-feedback modules in
`machines/blackmoon/home/default.nix`. See [desktop style ownership](../../../docs/desktop-style.md)
for the current configuration and test workflow. Other hosts retain their defaults.

Current appearance: charcoal app/notification surfaces, white text, illustrated
shell popups, a white title rail, 4px inner/zero outer gaps, and the approved
fade/slide/popin motion. The Acer instrument bar remains a Blackmoon module.
The greeter and boot theme are separate host imports.

The old provisional palette, isolated branch and temporary live deployment notes
are [archived](../../../docs/history/blackmoon-style-trials-2026-10.md). They are not
instructions for the current system.
